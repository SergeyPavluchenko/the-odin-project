# Testing Practice

A JavaScript testing practice project built as part of The Odin Project.

## Features

- `capitalize()`
- `reverseString()`
- Calculator
- `caesarCipher()`
- `analyzeArray()`

## Technologies

- JavaScript
- Jest
- CommonJS modules

## What I Practiced

- Writing unit tests
- Testing pure functions
- Using Jest matchers
- Testing edge cases
- Testing error handling
- Organizing code and tests into separate files

## How to Run

Install dependencies:

```bash
npm install
```

Run the tests:

```bash
npm test
```
