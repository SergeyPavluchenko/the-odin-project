# Binary Search Trees

A JavaScript implementation of a Binary Search Tree (BST) built as part of [The Odin Project](https://www.theodinproject.com/).

## Features

- Build a balanced binary search tree from an array.
- Insert new values into the tree.
- Delete values from the tree.
- Search for values in the tree.
- Traverse the tree using:
  - Level Order
  - In Order
  - Pre Order
  - Post Order
- Calculate the height of a node.
- Calculate the depth of a node.
- Check whether the tree is balanced.
- Rebalance an unbalanced tree.

## Technologies

- JavaScript (ES6+)
- Node.js
- Node.js built-in test runner

## Getting Started

Clone the repository:

```bash
git clone git@github.com:SergeyPavluchenko/the-odin-project.git
```

Navigate to the project directory:

```bash
cd the-odin-project/Full-Stack-JavaScript/JavaScript/binary-search-trees
```

Run the project:

```bash
npm run dev
```

Run tests:

```bash
npm test
```
