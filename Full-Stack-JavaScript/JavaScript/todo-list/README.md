# Todo List

A Todo List project built as part of The Odin Project.

## Features

- Add tasks
- Delete tasks
- Mark tasks as completed
- Mark tasks as important
- Filter all tasks
- Filter today's tasks
- Filter important tasks
- Save tasks to localStorage

## Technologies

- JavaScript
- Webpack
- ES Modules
- localStorage

## What I Practiced

- Classes
- ES Modules
- Rendering UI from application state
- Filtering data
- Persisting data with localStorage
- Working with Webpack

## How to Run

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
