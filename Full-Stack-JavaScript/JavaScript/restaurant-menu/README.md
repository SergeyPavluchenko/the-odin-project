# Restaurant Menu

A restaurant page project built as part of The Odin Project.

## Features

- Webpack setup
- JavaScript modules
- Dynamic DOM rendering
- Home section
- Menu section generated from JSON data
- About section
- Contact section
- Active navigation button state

## Technologies

- HTML
- CSS
- JavaScript
- Webpack
- ES Modules
- JSON

## What I Practiced

- Importing and exporting modules
- Splitting UI into components
- Rendering content dynamically
- Loading CSS and assets through Webpack
- Working with JSON data

## How to Run

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
