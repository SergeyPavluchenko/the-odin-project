# La Tavola — Restaurant Menu

A restaurant page project built as part of [The Odin Project](https://www.theodinproject.com/) Full-Stack JavaScript curriculum.

## Features

- Webpack setup (bundling, dev build, asset handling)
- JavaScript modules (import/export)
- Dynamic DOM rendering without page reload
- Home section
- Menu section
- About section
- Contact section
- CSS animations

## Technologies

- HTML
- CSS
- JavaScript
- Webpack
- ES Modules

## What I Practiced

- Importing and exporting modules
- Creating DOM elements with JavaScript
- Splitting UI into separate components
- Configuring and using Webpack
- Loading CSS and images through Webpack
- Switching page sections without reloading the page

## Getting Started

```bash
npm install
npm run start   # build with watch mode
npm run build   # production build
```
