# Tic-Tac-Toe

A simple Tic-Tac-Toe game built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

## Live Demo

[Play Tic-Tac-Toe](https://sergeypavluchenko.github.io/the-odin-project/Full-Stack-JavaScript/JavaScript/Tic-Tac-Toe/)

## About

This project is a browser-based Tic-Tac-Toe game for two players.

Players take turns placing `X` and `O` on a 3×3 game board. The game automatically checks for a winning combination after every move and detects a draw when all cells are occupied.

## Features

- Two-player Tic-Tac-Toe game
- Automatic turn switching between X and O
- Win detection
- Draw detection
- Prevents players from selecting an occupied cell
- Prevents clicks outside the game cells
- Restart game button
- Responsive layout
- Board generated dynamically with JavaScript

## Built With

- HTML5
- CSS3
- JavaScript
- Prettier
